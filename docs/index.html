Typoscope

for KOReader

Typoscope is a reading mask that keeps one line visible. It covers the text above and below the line that you read. The effect is the same as two sheets of paper on a printed page.

Install the plugin Source on GitHub

Installation

  1. Download the install ZIP file from the latest release.
  2. Extract the plugin folder from the ZIP file.
  3. Put the plugin folder in the plugins directory of KOReader. Make sure that the folder name is typoscope.koplugin.
  4. Start KOReader again.
  5. Open a book.
  6. In the menu, select Tools → More tools → Typoscope reading mask → Enable mask.

koreader/plugins/typoscope.koplugin/

Note: In some KOReader versions, Typoscope is directly under Tools. Before you read, assign Toggle typoscope to a gesture that is easy to remember. Then you can set the mask off quickly.

When you read

Touch the usual page-turn zones to move forward or backward through the lines. At the end of a page, one more touch turns the page or scrolls the view.

In Mask color, select light or dark. You can also adjust the line padding. You can set the cleaning flash on or off for each step. You can keep pages that have images fully visible.

The mask operates in reflowable books, for example EPUB files, in page mode and in scroll mode. The mask does not operate in PDF and DjVu documents. The text and the colors of the book do not change.
